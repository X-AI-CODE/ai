# 家族修仙/官途 — 单机微信小游戏设计文档

> 日期：2026-07-20
> 类型：单机微信小游戏
> 变现模式：IAA（纯激励视频）
> 渲染引擎：Three.js + Canvas 2D

---

## 1. 游戏世界观与路线

### 1.1 双路线设定

玩家开局选择**修仙世家**或**官宦世家**，两条路线独立，体验差异明显，鼓励重玩。

| 路线 | 核心目标 | 核心资源 | 战斗方式 |
|------|----------|----------|----------|
| 修仙 | 提升境界、培养后代飞升 | 灵石、功法、丹药 | 1vN 回合制打妖兽 |
| 官职 | 升官至顶级、家族权倾朝野 | 银两、政绩、人脉 | 部队战棋剿匪平叛 |

### 1.2 回合系统

以"年"为回合单位，每回合流程：

```
家族经营（分配族人/管理建筑）
  → 外出冒险（消耗体力进入副本）
  → 事件结算（随机家族事件/外部事件）
  → 下一年（家主年龄+1，寿命倒计时）
```

## 2. 家族系统

### 2.1 家族成员

| 角色 | 说明 |
|------|------|
| 家主 | 玩家直接操控，承担决策和冒险 |
| 族人 | 自然生成（配偶/子女/旁系），可分配任务 |
| 人口增长 | 联姻、新生儿，受声望和资源影响 |

### 2.2 角色属性

| 属性 | 作用 |
|------|------|
| 寿命 | 初始60-80岁，修仙可延寿，官职线固定 |
| 天赋 | 随机，影响修炼/政务效率，可遗传 |
| 资质 | 灵根（修仙）/ 才学（官职），决定成长上限 |
| 声望 | 家族综合影响力，影响联姻、事件、收入 |

### 2.3 传承机制

家主寿命耗尽 → 成年族人中选继承人 → 新家主继承：

- 天赋 × 继承系数（血脉等级越高，系数越大）
- 部分灵石/银两
- 建筑等级保留
- 声望衰减（血脉等级越高衰减越少）

---

## 3. 长线成长系统

### 3.1 血脉等级

家族全局等级，跨代保留：
- 达成里程碑升级（人口10人/培养出金丹修士/官至三品等）
- 加成：天赋继承比例、初期资源、最大寿命

### 3.2 功法/典籍传承（跨代）

| 路线 | 传承内容 | 效果 |
|------|----------|------|
| 修仙 | 功法、丹方 | 后代可直接修习，无需重新获取 |
| 官职 | 为官心得、人脉网 | 后代入仕起点更高 |

### 3.3 成就与里程碑

跨世代统计成就：累计培养X位元婴、累计产出Y万灵石
解锁：新建筑、新副本、新天赋池

### 3.4 难度递进

- 血脉等级越高 → 解锁高难度副本/强对手
- 外部环境周期性变化（朝代更迭、灵气潮汐）

## 4. 战斗与冒险系统

### 4.1 修仙线

| 维度 | 设计 |
|------|------|
| 战斗 | 回合制 1v1/1vN，Three.js 3D侧面视角，技能粒子特效 |
| 属性 | 灵力、功法等级、法宝、丹药Buff |
| 副本 | 按境界分层（练气→筑基→金丹→元婴），血脉等级解锁 |
| 掉落 | 功法碎片、炼丹材料、灵石、法宝 |

### 4.2 官职线

| 维度 | 设计 |
|------|------|
| 战斗 | 部队战棋，俯视视角，家主为统帅 |
| 属性 | 兵力、谋略、武艺、幕僚加成 |
| 副本地图 | 按官阶分层（剿匪→平叛→镇边），血脉等级解锁 |
| 掉落 | 银两、政绩、人脉令牌、兵书 |

### 4.3 共通

- 每回合约定的战斗体力，用完后只能经营
- 副本难度动态随血脉等级调整
- 激励广告：掉落翻倍 / 体力恢复 / 临时属性加成

---

## 5. 经营模块

### 5.1 建筑体系

| 建筑 | 修仙产出 | 官职产出 | 升级效果 |
|------|----------|----------|----------|
| 灵脉/庄园 | 灵石/时 | 银两/时 | 提升产量 |
| 丹房/书院 | 丹药 | 才学书卷 | 解锁高阶 |
| 修炼室/演武场 | 修为增长 | 武艺增长 | 加速成长 |
| 藏经阁/府库 | 功法传承+1 | 人脉传承+1 | 传承容量 |
| 祠堂 | 血脉经验 | 同左 | 两线共用 |

### 5.2 资源循环

```
灵石/银两 → 升级建筑 → 提高产出 → 更多资源
             ↓
       采购丹药/装备/兵书
             ↓
       提升战力 → 通关高副本 → 更强战力
```

### 5.3 族人分配

空闲族人可分配到建筑加速产出，资质影响加成。

### 5.4 内部事件

随机触发：族人生病、喜事、发现天才后代等，玩家做选择影响资源/人口。

## 6. 商业化设计

### 6.1 广告点位（全部激励视频）

| 点位 | 触发场景 | 奖励 | 日上限 |
|------|----------|------|--------|
| 行动点恢复 | 行动点用尽 | 恢复50%最大行动点 | 3次 |
| 体力恢复 | 战斗体力耗尽 | 恢复全部体力 | 3次 |
| 双倍掉落 | 副本结算 | 掉落翻倍 | 不限 |
| 族人加速 | 经营界面 | 效率×2持续2回合 | 5次 |
| 传承加成 | 选继承人时 | 继承比例+15% | 1次/代 |
| 寿命延寿 | 寿命≤3回合 | 延寿5回合 | 1次/代 |
| 签到翻倍 | 签到面板 | 签到奖励翻倍 | 1次/日 |

### 6.2 人均预期

| 指标 | 值 |
|------|------|
| 日活人均观看 | 5-8次 |
| eCPM | 15-40元 |
| 人均日收入 | 0.08-0.30元 |

## 7. 技术方案

### 7.1 技术栈

| 层级 | 方案 |
|------|------|
| 平台 | 微信小游戏 |
| 渲染 | Three.js（3D/2.5D场景 + 粒子特效） |
| UI层 | Canvas 2D overlay |
| 本地存储 | wx.setStorageSync |
| 广告 | wx.createRewardedVideoAd |
| 包体 | 主包精简，Three.js分包加载 |

### 7.2 项目结构

```
family-saga/
├── game.js              # 入口
├── game.json            # 配置
├── src/
│   ├── core/            # Three.js初始化、场景管理、主循环
│   ├── family/          # 家族系统
│   ├── battle/          # 战斗系统（两套逻辑）
│   ├── economy/         # 经营系统
│   ├── event/           # 随机事件引擎
│   ├── ad/              # 广告管理层
│   ├── storage/         # 存档
│   └── ui/              # HUD层（Canvas 2D）
├── libs/
│   └── three.module.js  # Three.js（分包）
└── res/                 # 资源
```

### 7.3 场景渲染

| 场景 | 方案 |
|------|------|
| 家族领地 | Three.js 俯视，Q版3D建筑 |
| 修仙战斗 | Three.js 侧面视角，粒子特效 |
| 官职战斗 | Three.js 俯视棋盘 |
| 数值/按钮/弹窗 | Canvas 2D overlay |

### 7.4 兼容

- 分包加载（主包 ≤4MB，总包 ≤20MB）
- 分辨率适配
- 后台自动存档
