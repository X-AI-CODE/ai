## 1. 游戏世界观与路线概览

《家族修仙/官途 (Family Saga)》是一款以 **“千秋世代、薪火相传”** 为核心的微信小游戏。玩家作为初代家主/家督，带领整个家族在漫长的岁月中繁衍、建设、修炼、出征，经历数百代传续，最终打造出一个屹立不倒的顶级世家。

游戏开局支持两条独立世界观路线，玩法差异显著：

| 维度 | 🌟 修仙世家 (Xianxia Route) | 🚩 官宦世家 (Official Route) |
|---|---|---|
| **核心终极目标** | 培育真灵仙根、培养大能渡劫飞仙 | 升官入京拜相、统帅部队权倾朝野 |
| **主要日常资源** | 灵石 (Stones)、功法残卷、九转仙丹 | 银两 (Silver)、政绩宗卷、人脉令牌 |
| **境界/官品进阶** | 凡人 $\rightarrow$ 练气 $\rightarrow$ 筑基 $\rightarrow$ 金丹 $\rightarrow$ 元婴 $\rightarrow$ 化神 $\rightarrow$ 飞升 | 秀才 $\rightarrow$ 九品 $\rightarrow$ 七品知县 $\rightarrow$ 五品知府 $\rightarrow$ 一品内阁 $\rightarrow$ 异姓王 |
| **核心战场玩法** | **3D 侧向回合制对决** (剑阵斩击/仙雷轰击/丹药护体) | **3D 俯视 8x8 沙盘战棋** (帅/骑/步/弓多兵种克制/相邻夹击+25%/军师锦囊) |

## 2. 玩家核心操作与界面使用指南

### 2.1 创角路线选择
初次打开小游戏（或选择删档重开）时，会弹出 **《双路线创角抉择》** 窗口：
* 点击 **【确定】** 开启 **修仙世家** 征程（初始获得：灵脉庄园、造化丹房、玄机修炼室、上古藏经阁、千秋祠堂）；
* 点击 **【取消】** 开启 **官宦世家** 征程（初始获得：繁华商铺、名门书院、铁血演武场、通事馆府库、千秋祠堂）。

### 2.2 顶部状态栏与核心资源
游戏顶部区域实时展示当前年份状态、资产数值以及快速补给按钮：
* **年份徽章**：显示 `【路线名】第 X 年 (代数: 第 Y 代)`。
* **行动点 (`行动点 X/10`)**：用于游历拜会世家、家主闭关等。用尽时点击右侧 `[+]` 按钮可观看短视频一键恢复 50% 行动点。
* **战斗体力 (`战斗体力 X/100`)**：每次挑战秘境/沙盘战役需消耗 $20 \sim 60$ 体力。耗尽时点击右侧 `[+]` 可观看视频瞬间回满。
* **快捷功能入口**：
  * `[🎁 福利/签到]`：进入商业化福利中心，领取每日基础签到或 **广告双倍签到**。
  * `[🌐 云排行/社交]`：进入微信云开发社交大厅，查看全服世家排行榜、提亲跨服姻缘、云同步存档。

### 2.4 世代更迭：薪火相传与血脉大选 (`HeirSelectUI`)

当家主岁数达到当前境界/头衔极限（或被重创）去世时，**游戏绝不会 Game Over**，而是立即弹出 **《薪火相传》** 候任大选面板：
1. 列表中会展示当前存活的所有成年子嗣或旁系英才。
2. 系统自动按照血脉遗传公式精确计算他们接班后的属性：
   $$\text{继承天资} = \text{候选人自身天资} \times \text{血脉系数} + \text{老家督天资} \times (1 - \text{血脉系数}) \times 0.5$$
3. **重要商业化策略**：在大选选定前，点击面板顶部的 **「📺 观看广告：传承比例额外 +15%」**，能够把天赋继承系数强化至极限 $95\% \sim 100\%$！选定继任者后，原老家主的**所有镇族至宝神兵 (`ArtifactManager.inheritToHeir`) 会 100% 转移认主给新任家主**！

## 5. 微信云开发 (CloudBase) 启用与数据库配置

项目内置的 `src/core/CloudAdapter.js` 现已做好了客户端与微信云开发 (`wx.cloud`) 的数据闭环对接。在上线真机云排榜与多端同步前，只需 3 步操作：

### 步骤 1：开启云开发并配置环境 ID
* 在开发者工具顶部点击 **「云开发」** 按钮开通。
* 复制概览页的 **环境 ID (`envId`)**。
* 打开 `src/core/CloudAdapter.js`，修改第 11 行的 `envId` 属性：
  ```javascript
  export const CloudAdapter = {
    isCloudReady: false,
    envId: '您的真实微信云环境ID', // 例如 'family-saga-cloud-env'
  ```

### 步骤 2：建立 3 个云端数据库集合 (Database Collections)
在云开发控制台 $\rightarrow$ **数据库** $\rightarrow$ 点击 `+` 创建以下集合，并设置数据权限：
1. **`user_saves`** (多端云存档库)
   - 权限设置：仅创建者可读写 (`doc(openid)`)。
2. **`global_leaderboard`** (全服千秋排行榜库)
   - 权限设置：所有人可读，仅创建者可写或通过云函数写。
   - 建议在云控制台为 `generation` 和 `bloodlineLevel` 字段建立降序索引 (`Index`)，加速查询。
3. **`public_heirs`** (全服跨服提亲姻缘池)
   - 权限设置：所有人可读写（或云函数管理）。

### 步骤 3：流量主服务端广告回调防刷配置（可选推荐）
为了彻底杜绝外挂跳过广告直接领奖：
* 在微信公众平台后台 $\rightarrow$ **流量主 $\rightarrow$ 广告设置 $\rightarrow$ 开启服务端发奖回调**。
* 将回调 URL 指向您的云函数 `adRewardVerify`，校验完成后再下发发奖 Token 给客户端。

## 6. 反作弊防篡改与防反编译构建指南

为了确保多周目排行榜和广告收入的绝对公平，底层集成了三重工业级黑客防护：

### 6.1 内存数值异或混淆 (`SafeNumber.js`)
* 在游戏运行时，敏感变量（如 `spiritStones` 灵石与 `silver` 银两）不再以普通数字存储，而是自动以 `Math.random() * 0x7fffffff` 生成动态掩码进行异或 (`_valEnc = val ^ _mask`) 并维护独立哈希。
* 任何试图使用 GG 修改器 / Cheat Engine 搜索明文内存或暴力改写内存地址的黑客，在下次调用 `.get()` 时都会立刻触发哈希比对失败，被系统截杀清零！

### 6.2 HMAC-SHA256 存档完整性防伪验签 (`AntiCheat.js` + `StorageManager.js`)
* 每次把本地进度写入 `wx.setStorageSync('family_saga_save_v1', data)` 前，`AntiCheat.signSavePacket` 都会使用带有混淆私有盐值 (`FS_SAGA_SEC_SALT_2026_X#9988$K!`) 对 JSON 字符串 + 时间戳生成加密 HMAC SHA-256 摘要 (`_hmac`)。
* 黑客如果导出本地存档、私自改写 JSON 里的数字字段后重新覆盖导入，在加载时 (`verifySavePacket`) 会因为缺少内部私有盐导致 HMAC 不匹配，弹出警报并拒绝载入！

### 6.3 生产发布构建期防反编译强混淆 (`obfuscator.config.cjs`)
* 请勿直接把 src 下的明文 JS 打包提交提审。在准备发布提审或打包真机包前，在终端运行项目预设的 NPM 命令：
  ```bash
  npm run build:obfuscate
  ```
* 脚本会调用 `javascript-obfuscator` 并读取 `obfuscator.config.cjs`，自动将逻辑代码转为 **控制流平坦化、变量名十六进制随机化、字符串 RC4 加密** 的高强混淆产物目录 `dist-obfuscated/`。
